

# Шаблон лендинга на React (Wireframe / Серый прототип)

Этот проект - стартовая заготовка сайта в нейтральном сером стиле. 
Сайт собран из отдельных блоков-компонентов. Ваша задача - взять эту основу и переделать под свою идею, услугу или продукт (поменять тексты, вставить свои картинки и настроить цвета).



## Быстрый старт: Как запустить проект

Перед началом убедитесь, что на компьютере установлена [Node.js](https://nodejs.org/).

### 1. Скачайте проект к себе на компьютер
Откройте командную строку VSCode и выполните:
```bash
git clone https://github.com/odium22/landing-wireframe.git
```

### 2. Перейдите в папку проекта
```bash
cd landing-wireframe
```

### 3. Установите зависимости
Команда скачает все нужные библиотеки (создаст папку `node_modules`):
```bash
npm install
```

### 4. Запустите сайт
```bash
npm run dev
```
После этого терминал покажет ссылку (обычно `http://localhost:5173`). Зажмите `Ctrl` (или `Cmd` на Mac) и кликните по ней - сайт откроется в браузере. Все правки в коде будут обновляться на странице мгновенно! (Так же если вдруг у вас не открывается локалхост, посмотрите не включен ли у вас ВПН)



## Что внутри и что где менять

Весь рабочий код находится в папке `src/`.

### 1. Главные файлы в корне `src/`

* **`App.jsx`** - **Главный пульт управления.**  
  Здесь ничего рисовать не нужно. Тут просто перечислены блоки сайта по порядку.
  * *Что делать:* если хотите поменять порядок секций - просто поменяйте строки местами. Если какой-то блок вам вообще не нужен - закомментируйте его (например, `{/* <Calculator /> */}`).
* **`App.css`** - **Внешний вид и дизайн.**  
  Здесь лежат размеры, отступы, сетка (Flexbox) и цвета кнопок. 
  * *Что делать:* когда решите покрасить серый сайт в свои цвета - меняйте цвета именно здесь.
* **`index.css`** - **Базовый сброс стилей.**  
  Убирает лишние браузерные отступы и заставляет сайт тянуться на всю ширину экрана. Трогать его обычно не нужно. Но можете поиграться `:D`



### 2. Папка `src/components/` (Ваши блоки)

Заходите в каждый файл по очереди и заменяйте текст на свои данные идеи или видение:

| Файл | Для чего нужен | Что там менять |
| :--- | :--- | :--- |
| **`Header.jsx`** | Шапка сайта | Напишите свое название проекта вместо `[ Мой Проект ]` и настройте ссылки меню. |
| **`Hero.jsx`** | Первый экран (Баннер) | Самое главное место. Напишите яркий заголовок (что вы предлагаете), краткое описание и подпишите кнопки действий. |
| **`Stats.jsx`** | Цифры и преимущества | 4 карточки с фактами о вашем проекте (опыт, сроки, гарантии, количество клиентов). |
| **`Services.jsx`** | Карточки услуг / товаров | 3 карточки с направлениями. Меняйте названия категорий, тексты, цены и вставляйте свои картинки вместо серых заглушек. |
| **`Calculator.jsx`** | Интерактивный калькулятор | Форма, где пользователь выбирает параметры и жмет «Рассчитать». Можно добавить свои поля или варианты в выпадающий список `<select>`. |
| **`Portfolio.jsx`** | Примеры работ («До / После») | Наглядная демонстрация результата вашей работы или готового продукта. |
| **`Contact.jsx`** | Форма обратной связи | Призыв оставить контакты в обмен на бесплатный шаг (консультация, смета, пробник, аудит). |
| **`Footer.jsx`** | Подвал сайта | Напишите свой ник/команду в копирайте и полезные ссылки. |


## Полезные советы для работы

1. **Как вставить картинку?**  
   Положите файл картинки в папку `public/` (например, `photo.jpg`) и используйте в коде:  
   `<img src="/photo.jpg" alt="Описание" />`. (если нет папки, создайте её)
2. **Не бойтесь ломать!**  
   Если после изменения в коде появилась ошибка - браузер и терминал покажут номер строчки, где вы ошиблись (часто это просто забытая закрывающая скобка `>` или кавычка).
3. **Перед отправкой работы:**  
   Проверьте, чтобы на сайте не осталось текстов в квадратных скобках вида `[ Фото 1 ]` или шаблонных фраз «Здесь напишите текст».
